# Security reports

English · [Français](SECURITY.fr.md)

For vulnerabilities in this automation, use **Security → Report a vulnerability** if private reporting is enabled on this repository. Do not publish secrets or an actionable exploit in a public issue. If private reporting is unavailable, use a private channel you already have with the maintainer; no personal contact address is published here.

For vulnerabilities in Hermes itself, follow upstream disclosure instructions. These packages do not establish an official Nous Research support channel.

Include the distribution tag, affected workflow or file, impact and a minimal reproduction. Redact credentials, Gateway addresses and unrelated personal data. Account for ad-hoc signing and the absence of Apple notarization when assessing installation behavior.

This repository does not promise a response deadline or security support for historical packages. Prefer the latest successful packaging revision.
